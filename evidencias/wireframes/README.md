# Wireframes

Estos wireframes documentan la arquitectura de información utilizada para consolidar la interfaz:

1. `01-dashboard.svg`: resumen, carga rápida y estado de actividad.
2. `02-archivos.svg`: búsqueda, filtros y administración de evidencias.
3. `03-evaluacion.svg`: consulta agrupada para revisión y calificación.

Se presentan como wireframes de baja fidelidad: describen jerarquía, agrupación y flujo, no colores finales ni detalles decorativos. Deben acompañarse con una explicación oral de las decisiones y, si el grupo realizó bocetos previos, añadirse también las fotografías o capturas originales.
