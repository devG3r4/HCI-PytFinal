# Proto-persona

Este perfil se deriva del contexto académico descrito por el profesor. No sustituye una entrevista: se utiliza como hipótesis de diseño que debe validarse con estudiantes.

## Alex, estudiante universitario

- **Contexto:** cursa HCI y trabaja con entregas repartidas entre su computadora, OneDrive y chats del grupo.
- **Objetivo:** encontrar rápidamente una evidencia, saber a qué categoría pertenece y mostrarla durante una revisión.
- **Necesidades:** nombres claros, categorías visibles, búsqueda, carga de archivos y una vista resumida para revisar el avance.
- **Frustraciones:** archivos con nombres inconsistentes, carpetas profundas, pérdida de versiones y no saber si una acción se guardó.
- **Comportamiento esperado:** primero consulta el resumen; después registra o busca una evidencia; finalmente abre el archivo o revisa la vista de evaluación.

## Hipótesis que deben validarse

1. Las cuatro categorías son más comprensibles para el curso que “Unidad 1, 2 y 3”.
2. El estudiante reconoce “Nueva evidencia” como la acción principal.
3. La vista de evaluación resulta útil para revisar entregas sin abrir cada tarjeta.
4. Los mensajes de confirmación reducen la incertidumbre después de guardar o eliminar.
