# Evidencias de HCI y Diseño Centrado en el Usuario

Esta carpeta reúne los artefactos que explican cómo se tomó cada decisión de diseño. La evidencia está separada en dos tipos:

- **Aplicada y verificable en el repositorio:** análisis de requisitos, proto-persona, arquitectura de información, recorrido cognitivo y evaluación heurística.
- **Lista para aplicar con participantes:** encuesta, guion de prueba de usabilidad y plantilla de resultados.

No se presentan respuestas inventadas. El grupo debe completar la prueba con estudiantes reales, anexar capturas o fotografías del proceso y reemplazar la plantilla de resultados con los hallazgos observados.
