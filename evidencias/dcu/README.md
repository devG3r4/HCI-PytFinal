# Evidencias de HCI y Diseño Centrado en el Usuario

Esta carpeta reúne los artefactos que explican, de forma sencilla, cómo fuimos tomando las decisiones de diseño. La evidencia está separada en dos tipos:

- **Aplicada y verificable en el repositorio:** análisis de requisitos, proto-persona, arquitectura de información, recorrido cognitivo y evaluación heurística.
- **Lista para aplicar con participantes:** encuesta, guion de prueba de usabilidad y plantilla de resultados.

La prueba con estudiantes todavía no se ha realizado. Por eso no presentamos respuestas inventadas como si fueran una encuesta real. Antes de entregar, el grupo debe probar el prototipo con compañeros, guardar sus observaciones y completar la plantilla con esos resultados.
